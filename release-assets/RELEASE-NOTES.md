Kiro Password Manager 1.0.17 for macOS Apple Silicon.

- Manage encrypted local vaults with folders, tags, search, password generation, TOTP, edit history, and backups.
- Filter accounts using tag badges in the sidebar.
- Choose a bundled brand logo, an image URL, or a website favicon. Images remain cached until you replace them.
- Choose from an expanded logo catalog, including WeChat, Messenger, and major international banks.
- See each account's last update on the right: the time for today, day/month for other dates in the current year, and day/month/year for dates in other years.
- Use a different masking pattern each time you preview part of a password.

Download KiroPasswordManager_1.0.17_arm64.app.tar.gz for macOS 13 or later on Apple Silicon. Extract the archive, move Kiro Password Manager.app into Applications, quit any older instance, and open the new app.

This early access build is ad hoc signed and has not been notarized by Apple. The updater verifies its separate signed package; that signature does not replace Apple notarization.

Validation: lint and TypeScript checks passed, 157 automated tests passed, four renderer end-to-end tests passed, and the packaged updater signature and installation were verified in a disposable test application.
