Kiro Password Manager 1.0.17 for macOS Apple Silicon.

- Manage encrypted local vaults with folders, tags, search, password generation, TOTP, history, and backups.
- Filter accounts from the sidebar tag cloud.
- Choose a bundled brand logo, an image URL, or a website favicon. Saved images remain cached until you replace them.
- Use the expanded logo catalog, including WeChat, Messenger, and major international banks.
- See each account's last update on the right: time for today, day/month within the same year, and day/month/year for older years.
- Randomize the concealed positions each time partial password preview is used.

Download KiroPasswordManager_1.0.17_arm64.app.tar.gz for macOS 13 or later on Apple Silicon. Extract the archive, move Kiro Password Manager.app to Applications, quit any older instance, and open the new app.

This early access build is ad hoc signed and has not been notarized by Apple. The updater verifies its separate signed package; that signature does not replace Apple notarization.

Validation: lint and TypeScript checks passed, 157 automated tests passed, four renderer end-to-end tests passed, and the packaged updater signature and installation were verified in a disposable test application.
