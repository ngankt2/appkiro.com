Kiro Password Manager 1.0.17
macOS 13 or later, Apple Silicon (arm64)

Website: https://appkiro.com

Installation
1. Extract KiroPasswordManager_1.0.17_arm64.app.tar.gz.
2. Move Kiro Password Manager.app into Applications.
3. Quit any older instance, then open the new app.

This early access build is ad hoc signed and has not been notarized by Apple.
The updater package signature does not replace Apple code signing or notarization.
